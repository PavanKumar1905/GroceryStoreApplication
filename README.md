# GroceryStoreApplication
A full-stack Grocery Store Management System built with HTML, CSS, JavaScript, Bootstrap, Python (Flask), and MySQL. It simplifies product, inventory, customer, and order management through a responsive interface and efficient database-driven operations.

In this python project, we will build a grocery store management applicaton. It will be tier application,

  1. Front end: UI is written in HTML/CSS/Javascript/Bootstrap
  2. Backend: Python and Flask
  3. Database: mysql
